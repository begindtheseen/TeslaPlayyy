# CanvasTube — independent custom canvas player starter

A starter for a TeslaPlay-style *architecture*, not a copy of TeslaPlay or a finished YouTube streaming service. Bundled synthetic video is original test material.

## Quick start

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000. Use the **Play demo** button to test local MPEG-TS -> worker -> WebCodecs -> OffscreenCanvas (video-only experimental implementation). Add `YOUTUBE_API_KEY` in `.env.local` for metadata search. YouTube result playback deliberately returns 501 until an authorized media backend exists.

**Give Claude Code the repository and tell it to read `CLAUDE_HANDOFF.md` first.** Architecture contract and phase checklist live in `docs/`. The worker is a prototype; TS parser edge cases, AAC audio, seeking and device validation are not complete.

## Technical notes
- H.264 baseline, 640x360, 24fps, 5s, MPEG-TS local demo generated by FFmpeg.
- Browsers require secure context for some APIs in production; localhost is generally supported. Test WebCodecs and OffscreenCanvas availability explicitly.
- Only test vehicle playback while parked. Browser support does not establish that a vehicle's safety restrictions can or should be bypassed.
